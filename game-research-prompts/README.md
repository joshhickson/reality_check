# Game Research Prompts

This directory contains a series of detailed research prompts. These prompts are designed to be used with a large language model (like Google Gemini 2.5 Pro) to analyze the "Reality Check" game and generate actionable insights for its improvement and success.

The prompts focus on the following key areas:
- Game Design Document (GDD)
- Player Manual
- Bot Simulator and Testing Strategy
- Player Cards and Game Element Balance
