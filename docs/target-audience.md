# Target Audience Profile

*This document defines the target player for "Reality Check" to ensure that design, marketing, and development decisions are aligned with player expectations and motivations.*

## Primary Audience: The "Social Gamer"

*   **Age Range:** 25-40
*   **Motivations:**
    *   Enjoys narrative-forward, thematic board games.
    *   Seeks shared social experiences and conversation-starters.
    *   Appreciates satire and dark humor that critiques modern society.
    *   Is not purely competition-driven; values the story and experience as much as winning.
*   **Examples of Other Games Enjoyed:** *The Grizzled*, *Fog of Love*, *Dead of Winter*, *Red Flags*.
*   **Other Media Consumed:** *Black Mirror*, *The Onion*, *Succession*.

## Secondary Audience: The "Light Strategist"

*   **Motivations:**
    *   Enjoys games with meaningful choices and light-to-medium strategic depth.
    *   Appreciates clever mechanics but is turned off by overly complex, "heavy" Eurogames.
    *   Values thematic integration, where mechanics reinforce the game's story and premise.

## Player Experience Goals

*   Players should laugh and say, "This is hilarious because it's true."
*   The game should generate memorable, player-driven stories.
*   Choices should feel impactful and thematically resonant.
*   The experience should be a fun, social centerpiece for a game night, not a silent, optimization-focused puzzle.
