# Component List

*This document provides a comprehensive list of all physical and digital components required for "Reality Check." This serves as a master list for prototyping, production costing, and manufacturing.*

## Physical Game Components

### Board
*   1x Main Game Board (Dimensions TBD)
    *   Includes tracks for Community Impact.

### Cards
*   **Card Size:** Standard Poker Size (2.5" x 3.5")
*   ~50x Sin Cards
*   ~50x Virtue Cards
*   ~30x Crossroads Cards
*   ~10x Secret Objective Cards (for Exile Protocol)
*   4x Player Aid Cards

### Tokens & Markers
*   **Material:** Punchboard
*   Player Pawns (1 per player, in 4-5 distinct colors)
*   Resource Trackers (4 per player, for Money, Mental Health, Sin, Virtue)
*   Action Point Tokens (2 per player)
*   "Kudos" Tokens (~10-15)
*   "Concern" Tokens (~10-15)
*   Social Capital Tokens (~30-40)

### Dice
*   2x Standard six-sided dice (d6)
